# Number Guessing Game

## Description
A beginner-friendly JavaScript mini-project where the player guesses a randomly generated number between 1 and 10.

## Features
- Random number generation
- Feedback for high and low guesses
- Maximum of five attempts
- Win and game-over messages

## Technologies
- HTML
- JavaScript

## How to Run
1. Download the project files.
2. Open `index.html` in a web browser.
3. Enter a number and click Guess.
